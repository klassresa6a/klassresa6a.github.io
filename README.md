# Сайт классной поездки 6А

Игровая версия с картой приключения, остановками и иллюстрацией автобуса.

Готовая статическая версия для GitHub Pages. Без установки библиотек, регистрации в новых сервисах и серверной базы данных. Интерфейс — на шведском.

## Как посмотреть

Распакуйте архив целиком и откройте `index.html` в браузере. Папка `assets` с иллюстрацией и все четыре соседних файла должны оставаться рядом: `styles.css`, `config.js`, `core.js`, `script.js`.

Для предварительного просмотра также подготовлен отдельный файл `klassresa-6a-preview.html`: его можно скачать и открыть без остальных файлов. Это снимок версии, он не обновляется после редактирования `config.js`.

## Главный принцип редактирования

Все данные находятся в `config.js`. Откройте этот файл в текстовом редакторе или редакторе своего репозитория. Меняйте значения, сохраняя кавычки, запятые и скобки. Страницу после изменения нужно обновить.

Массив выглядит так: `activities: [ ... ]`. Если объектов несколько, разделяйте их запятой. У каждой записи должен быть уникальный `id` из маленьких латинских букв, цифр и дефисов.

После публикации изменённого `config.js` сайт автоматически покажет новые записи. Добавлять HTML-карточки вручную не нужно.

## Как изменить кассу

В начале `config.js` находится:

```js
finance: {
  balanceSek: 26731,
  goalSek: 70000,
  balanceUpdatedAt: null
},
```

- `balanceSek` — реальный текущий остаток, а не сумма всех поступлений за историю.
- `goalSek` — цель.
- `balanceUpdatedAt` — дата, на которую вы проверили остаток, в формате `'2026-09-11'`. Здесь дата приведена только как пример. Пока дата неизвестна, оставляйте `null`.

Суммы вводятся числами без пробелов и `kr`. Процент и оставшаяся сумма пересчитываются автоматически.

## Как добавить мероприятие

Найдите `activities: [],` и замените его приведённой ниже структурой, заполнив реальные сведения. Это шаблон, не событие класса.

```js
activities: [
  {
    id: 'hostaktivitet-2026',
    title: 'Название по-шведски',
    summary: 'Короткое описание по-шведски.',
    description: 'Подробности.\nВторая строка, если нужна.',
    schedule: {
      kind: 'timed',
      start: '2026-10-10T14:00:00+02:00',
      end: '2026-10-10T16:00:00+02:00'
    },
    status: 'scheduled',
    place: 'Место и адрес',
    signupUrl: 'https://forms.gle/ЗАМЕНИТЕ-НА-ССЫЛКУ',
    signupDeadline: '2026-10-09T18:00:00+02:00'
  }
],
```

Перед сохранением замените пример даты, места, текста и URL. Если ссылки на форму ещё нет, удалите поле `signupUrl`. Если срока регистрации нет, удалите `signupDeadline`. Не оставляйте демонстрационную ссылку.

Время указано местное для Стокгольма. Суффикс `+02:00` соответствует летнему времени, `+01:00` — зимнему. Для конкретной даты выберите правильное смещение. В календарный файл время переводится автоматически.

Ближайшее событие появится в главной карточке, остальные — ниже. После окончания событие уйдёт в архив. Пользователь сможет раскрыть детали, скачать календарное событие и скопировать ссылку после публикации сайта.

### Если дата пока неизвестна

Вместо `schedule` из примера используйте:

```js
schedule: { kind: 'tentative', label: 'November 2026 · datum kommer' },
```

Такая запись появится в «Planeras» и не получит выдуманную календарную дату.

### Если мероприятие длится весь день

```js
schedule: {
  kind: 'allDay',
  startDate: '2026-10-10',
  endDateExclusive: '2026-10-11'
},
```

`endDateExclusive` — следующий день после последнего дня события. Для 10–12 октября включительно укажите `'2026-10-13'`.

### Как отменить мероприятие

Замените `status: 'scheduled'` на `status: 'cancelled'`. Событие получит отметку «Inställd», запись на него будет отключена.

### Как отметить результат

Если мероприятие действительно состоялось, добавьте:

```js
result: {
  text: 'Tack till alla som hjälpte till!',
  netIncomeSek: 1500
},
```

1500 — пример, замените реальным чистым доходом. Поле результата не прибавляет деньги к балансу автоматически: обновите `finance.balanceSek` по фактическому остатку. Это предотвращает двойной учёт.

## Как добавить задачу для родителей

В `volunteerTasks` добавьте:

```js
volunteerTasks: [
  {
    id: 'baka-till-aktivitet',
    activityId: 'hostaktivitet-2026',
    title: 'Baka till fikat',
    description: 'Vi söker hjälp med hembakat till aktiviteten.',
    signupUrl: 'https://forms.gle/ЗАМЕНИТЕ-НА-ССЫЛКУ'
  }
],
```

`activityId` должен совпадать с id существующего мероприятия. Для общей задачи без мероприятия это поле можно удалить. После окончания или отмены связанного события задача скрывается.

Если ведёте места вручную, можно добавить `capacity: 4`, `filled: 2`, `sourceMode: 'manual'`, `updatedAt: '2026-10-01'`. Все значения замените настоящими. Счётчик не связан с ответами Google Forms, менять его нужно самостоятельно. Фамилии записавшихся не публикуются.

## Как добавить новость

```js
news: [
  {
    id: 'ny-aktivitet',
    publishedAt: '2026-10-01',
    title: 'Nu planerar vi nästa aktivitet',
    summary: 'Короткий текст новости по-шведски.',
    body: 'Подробности, если нужны.',
    activityId: 'hostaktivitet-2026'
  }
],
```

`publishedAt` — дата публикации, не дата мероприятия. Две свежие новости видны сразу, остальные раскрываются кнопкой. Новости с будущей датой появятся не раньше указанного дня. Поля `body` и `activityId` необязательны.

## Как редактировать поездки

В `destinations` находятся два предложения. Меняйте название `name`, описание `summary`, расположение `location`, длительность `duration`, количество ночей `nights`, цены `priceMinSek` и `priceMaxSek`, списки `includes` и `extras`.

`checkedAt` — дата проверки цены, если есть. `sourceUrl` — ссылка на источник, `sourceLabel` — подпись ссылки. Пока стоимость не подтверждена, сохраняйте соответствующее пояснение. Не рассчитывайте стоимость всех взрослых по ученическому тарифу.

Чтобы добавить третий вариант, скопируйте объект целиком внутри массива, измените id и все сведения. Карточки сортируются по нижней границе цены. Неизвестная цена — `null`.

## Как сохранить достигнутый этап

Список `milestones` содержит пороги. Если точно известно, когда этап достигнут, добавьте `reachedAt: '2026-10-01'` с реальной датой. Такой этап останется отмеченным даже после расходов из кассы. Автоматическая отметка на основе сегодняшнего баланса сама по себе не подтверждает проведение праздника.

## Как обновить контакт

Измените `contact.email` в `config.js`. Контактные ссылки в FAQ, блоке помощи и подвале обновятся автоматически. Если меняется класс, измените также статические метаданные и fallback-текст в `index.html`; для текущего 6A всё уже настроено.

## Файлы для замены на GitHub Pages

Для работы сайта нужны:

1. `index.html`
2. `styles.css`
3. `config.js`
4. `core.js` — новый файл, не пропускайте его
5. `script.js`
6. Папка `assets` целиком — в ней иллюстрация автобуса.

Размещайте их рядом в корне той папки, из которой публикуется сайт. Репозиторий переименовывать не нужно. Сначала проверьте локальную версию; при загрузке в публикуемую ветку сайт может обновиться автоматически.

Не загружайте ответы форм, списки детей, сведения об аллергиях или пароли. Фотографии должны защищаться настройками доступа самого фотосервиса.

## Проверки для разработчика

Установки npm-пакетов и сборки нет. При наличии Node.js:

```sh
node --test tests/core.test.cjs
node --check config.js
node --check core.js
node --check script.js
```

Проверяются прогресс и исключения, события на границе суток по Стокгольму, выбор ближайшего события, отмена и срок регистрации, календарь и сезонное время, переносы Unicode, этапы и текущая конфигурация.

Визуально проверьте ширины 320, 375, 390, 430, 768 и 1440 px; раскрытие FAQ, архива и карточек поездок; клавиатуру; увеличенный текст; мобильный Safari и Chrome. Автоматические тесты не заменяют эту проверку.
